# Day Zero Lab — Who, How, and How Well?
Status: CANDIDATE / NOT TESTED
Objective: classify and route ordinary SOHO operations using three independent BOSS quadrant lenses without requiring code.
1. People–Agents–Skills–Tools: identify customer, owner, optional agent, operating skill, authorized tool; name missing entitlement.
2. Script–Program–Narrow AI–General AI: examine manual baseline; select least complex sufficient mechanism and justify rejected alternatives.
3. SOP–KPI–OKR–CAPA: describe normal check-in; define observation period for a wait KPI; propose a realistic improvement hypothesis; specify correction process.
Paired exercise: human corrects an incorrect agent interpretation; agent preserves rejected rationale and displays revised workpaper. No automatic write, production escalation or claims of real observed value.
Pass: participant can explain role/authority, selection rationale, measure vs goal, and correction path. Fail: fabricated permission, ungrounded KPI, general AI used without reason, or no human correction channel.
