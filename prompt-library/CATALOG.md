## Selection logic for Day Zero

**Survey:** identify task, learner's current position and available source.  
**Evaluate:** choose creative, research, audit or production role; recognize authority boundaries.  
**Validate:** check source integrity and input completeness before prompt use.  
**Execute:** send approved prompt to the right model/tool, record evidence.  
**Normalize:** extract the transferable pattern, review findings and version the library entry.

This SEVEN discipline is a pedagogical candidate; a prompt's existence does not authorize execution or release.
