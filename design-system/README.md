# Design system

## Engineering graphics

[`engineering-library/`](engineering-library/README.md) contains the candidate technical graphics collection: 286 ISO-referenced process symbols, 75 mechanical drafting elements, seven ANSI/IEEE logic gates, original source files with pinned provenance, and React composition adapters.

Build its searchable atlas with `npm ci && npm run build` inside that directory. Use the source records, licensing and standard-scope notes when selecting components. Generic layout containers are not the project's technical graphics library.

## Visual profiles

Episode 01 follows the root `AGENTS.md` interface profile: white ground, black live text, measured grids, cyan #00BCEB and magenta #E30074 reserved for original identity and selective emphasis. The older composition doctrine remains historical context; do not silently mix palettes or retired metaphors.

Technical geometry, original story illustrations, original bioscillate brand assets and live editorial text remain separate layers. A component import is not slide approval, standards certification or Canva editability verification.
