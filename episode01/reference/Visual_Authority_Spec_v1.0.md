# BOSS Episode 01 — Visual Authority Spec v1.0
**Project:** BOSS · Episode 01 — The Pitch
**Application:** React/Tailwind Presentation Viewer
**Status:** Locked for Implementation

## 1. The Design Metaphor
The visual interface must behave like a premium technical operating system, specifically inspired by the Tesla Model Y center touchscreen UI combined with CAD/ISO technical drafting.
* **Information Density:** High. The layout must support substantial text, instructional sidebars, and sequence diagrams without feeling cluttered.
* **Zoning:** Precise spatial organization. Use panel logic, top technical metadata rails, and boxed sequence steps.
* **Composure:** Calm, modern, and intelligent. Clean lines and clear hierarchy replace decorative elements.
* **Prohibited Metaphors:** Marketing landing pages, giant empty hero sections, oversized "website" typography, generic SaaS feature cards.

## 2. Brand Identity & Color Palette
The canonical bioscillate brand identity is the sole source of color and emphasis.
* **Base Structure:** Pure White (`#FFFFFF`) canvas, Black (`#000000`) typography and structural lines, and Grayscale for secondary UI elements.
* **Brand Colors:** Cyan and Magenta. Used exclusively for brand identity, data visualization, and selective emphasis.
* **Logo Usage (Full):** Slide 01, final closing slide, and major section dividers. Must include the Cyan waveform (left), Black central connector/diamond, Magenta fragmented waveform (right), Black lowercase "bioscillate" wordmark, and monospace "Operating System by Seven" tagline.
* **Logo Usage (Reduced):** Compact mark + wordmark for the top metadata rail on internal instructional slides.

## 3. Structural Constraints
* **Canvas:** Fixed `1920x1080` logical aspect ratio (16:9), scaled dynamically via CSS to fit the viewport.
* **Geometry:** 1px hairline rules, measured padding, structural grid alignment. No thick (e.g., 8px) decorative borders or drop shadows.
* **Technology:** Native HTML/CSS. All text (headlines, body, captions) must be native, selectable HTML elements to preserve Canva import viability. No full-slide SVGs.
