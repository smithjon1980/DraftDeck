# Day Zero Supplemental Asset — The Bioscillate Prompt Library

**Status: CANDIDATE / HUMAN CURRICULUM REVIEW PENDING**

The [Bioscillate Governed Prompt Library](../../prompt-library/README.md) is a proposed Day Zero teaching artifact. It contains reusable model instructions extracted and adapted from actual BOSS/DraftDeck/NotebookLM work, with source lineage and operational boundaries. It is **not** a substitute for source documents, genuine authorization, executable skills, or independent QA.

## Why teach it

The learner should understand the difference between:

- A prompt that asks a model to explore possibilities;
- A governed skill that defines repeatable steps and evidence;
- A locked production contract that requires exact content;
- A human decision that authorizes which result proceeds.

NotebookLM/Gemini-generated podcast, slide, video and infographic outputs are **private inspirational sparks**. A public podcast needs an approved word-for-word script and verified speech production. The library should help a learner take the idea from curiosity through bounded experimentation and into controlled manufacturing.

## Day Zero activity (candidate)

Give the learner two prompts that appear plausible, but one lacks source requirements, authority boundaries or stop conditions. Ask them to identify the missing constraints; improve the prompt using [PROMPT_TEMPLATE.md](../../prompt-library/PROMPT_TEMPLATE.md); test it on a supplied source; observe inaccuracies; reflect on why better constraints and feedback matter; and archive a candidate version.

**Assessment:** Explain the difference between creative exploration and governed execution and defend the role-specific information access of Gemini as research critic versus production supervisor.

No assertion of learning efficacy is made until tested. The curriculum route and competency rubric still require human review and validation.
