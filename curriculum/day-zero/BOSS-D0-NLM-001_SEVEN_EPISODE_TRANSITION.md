## Ratified learning architecture
**Day Zero is a competency boundary, not a one-day or one-hour duration.** Episodes 01–07 may be watched serially, binged, or completed at the learner's own pace. Content should support Watch / Try / Prove, with optional facilitator workshop adaptation. Deliverable media length is not capped to one hour for the entire Day Zero.

| Episode | New working scope | Observable learning outcome |
| --- | --- | --- |
| 01 | Passenger to Operator | Distinguish human intent, AI application, underlying model, and execution authority. |
| 02 | Instructions and Boundaries | Write a repeatable skill or procedure with explicit constraints and success conditions. |
| 03 | The Handoff | Manually relay an authenticated shared frame; distinguish APIs, MCP, plugins, and tool results without asserting unsupported connections. |
| 04 | Inside the Sandbox | Observe a bounded execution; contrast requests, attempts, execution, and evidence. |
| 05 | What Survives? | Distinguish ephemeral runtime from durable storage, manifests and provenance. |
| 06 | Package the Environment | Explain reproducible environments, Docker and dependencies, including limits of analogy. |
| 07 | Build Your Command Kit | Integrate the governed pieces in a bounded assessed exercise; discuss suitable local hardware as optional extension. |

Every episode: **Watch → Try → Prove**, explicit inputs, demonstration or illustrative fixture, evidence criteria, unknowns, correction path and next-episode bridge. No required commercial account or live deployment for the conceptual competency path. A real sandbox demonstration requires the actual runtime and an execution receipt.
