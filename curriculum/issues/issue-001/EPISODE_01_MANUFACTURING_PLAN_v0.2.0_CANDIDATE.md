## 3. Authoring and controls

1. **SOURCE_ADMISSION** — read the Issue Source Manifest, ratified §6.04 and §6.05, current GRF candidate, lexicon gateway, competency anchors, and admitted evidence. State all limitations.
2. **PICK_AND_PULL** — select, extract, inspect, fit, and submit promising Creative Spark material as candidate ideas. Preserve original audio/transcript untouched; cite time locators, not invented external proof.
3. **SCRIPT_DRAFT** — create stable PART, ACT and turn identifiers. Each factual or doctrinal statement maps to a source and evidence state. Do not use the retired human-like diagnostics in operative narration.
4. **SCRIPT_REVIEW_HOLD** — human reviews exact words, learning value, pacing, terminology, source claims, speaker mapping, sound rights, and assessment work products.
5. **SCRIPT_LOCKED** — hash exact approved UTF-8 script bytes and bind script version, approved voice/delivery/pronunciation manifest, human decision, part ID and allowed provider parameters.
6. **SYNTHESIS_CANDIDATE** — synthesize bounded segments, record provider/model, duration, segment identities, compute/cost and SHA-256 output identities. The synthesizer has no editorial rewriting authority.
7. **AUDIO_QA_HOLD** — independent ASR or forced alignment where feasible, plus human listening, compare words, pronunciation, pauses, line joins, rights, and speaker identity. Mechanical checks do not certify all auditory quality.
8. **PATCH_REVIEW** — perform single-segment regeneration when validated by the chosen engine; compare adjacent joins; any change to approved words returns to script review and relock.
9. **HUMAN_RELEASE_HOLD** — verify evidence and final audio; only a human with release authority can approve distribution.
10. **PROGRAM_ASSEMBLY** — record part completion, covered competencies, real accepted runtime and remaining hours toward the 24-hour goal. Do not sum unpublished candidate runtime as finished content.

## 4. Distinct acceptance metrics

**Manufacturing tests:** exact-script spoken-word fidelity, stable speaker/voice, accepted pronunciation, splice quality, file integrity, source traceability, and legal/rights review.

**Teaching tests:** learner can state destination/constraints; classify evidence and errors; perform Pick-and-Pull with reasons; map source-to-claim; specify failure detection; supply an inspectable work product.

Neither type of test substitutes for the other.
