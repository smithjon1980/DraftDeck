## How to reproduce

On a connected Linux machine with Chrome, Node 22, Java 17, Python 3 and access to npm/Maven Central:

```bash
cd examples/diagram-react-v01
export PUPPETEER_SKIP_DOWNLOAD=1
npm install --no-audit --no-fund
bash scripts/render-engines.sh
npm run build
cp index.html dist/index.html
CHROME_BIN="$(command -v google-chrome)" npm run render:browser
```

Outputs in `dist/diagrams` are generated by **real diagram compilers**; `screenshots/` contains PNG, browser-printed PDF, and a JSON runtime report. In GitHub Actions, see the *BOSS real diagram engines + React browser proof* workflow and its `boss-mermaid-plantuml-react-browser-proof` artifact.

The PlantUML JAR is checked against Maven Central's SHA-256 sidecar. These are direct version pins; **a committed npm lockfile is not yet present** in the initial candidate and must be added after reproducible npm resolution before declaring the entire dependency graph locked.
