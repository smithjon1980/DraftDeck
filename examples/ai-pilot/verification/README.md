# Verification

The files in this directory separate **adapter-route evidence** from **current flagship verification**.

- `Canva_Baseline_Verification.json` records the earlier proof that the DraftDeck HTML → Canva route can preserve editable page structure, rich text, and separate images.
- `Production_Notes.md` records the current Logistics Framework build state.

The baseline does **not** certify the current Logistics Framework deck. A fresh Canva import must complete:
1. layer/dimension inspection;
2. rendered visual review;
3. edit/save/reopen round trip.

Only then should a new current verification record be added.
