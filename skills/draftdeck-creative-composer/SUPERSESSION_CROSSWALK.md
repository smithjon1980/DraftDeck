## Precedence mechanism and enforcement debt

Before any default-route promotion, an authorized rebuild must update the central skill router, docs, schemas, tests, and CI to make the distinction executable and unambiguous. The current Go-based workflows are **not removed** and should not be called on this trial as if they establish React composition compliance.

Use route identity `draftdeck-creative-recomposition-v1-candidate` in future run manifests, and reject mixed legacy reconstruction / new recomposition contracts without explicit human routing decision. Record old-to-new document mapping in Git history. Promotion or deletion of legacy machinery requires separate authorization.

**Do not confuse:** (1) proposal to supersede, (2) experimental-branch commit, (3) verified running implementation, and (4) ratified production release.
