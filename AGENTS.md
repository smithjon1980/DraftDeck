# Shared assistant working instructions

Applies to this repository. Kimi, Gemini and other assistants should be explicitly directed to read this file if their environment does not automatically load it.

1. Read START_HERE.md and coordination/CURRENT_HANDOFF.md before continuing. Confirm the branch and exact commit you inspect.
2. Follow the authority stack and document statuses in doctrine/README.md. Candidate material is not automatically canonical because it is committed or merged. Surface conflicting requirements.
3. Preserve existing source paths. Author production changes in source; generated outputs are overwritten. Follow doctrine/production-contract.md. No PowerPoint intermediary.
4. Keep Day Zero focused on local-device manual communication between AI systems. Windmill training starts on Day One; do not silently move automation into Day Zero.
5. Retain PRIME = Package → Route → Inspect → Move → Establish Delivery. Admission, output adjudication and release are governing boundaries, not extra letters.
6. Distinguish requested, attempted, observed, verified and authorized actions. Capability and schema validity do not grant permission. Review strength follows consequence; do not assume every output needs manual approval.
7. Link manuscript claims to versioned sources and actual records in research/EVIDENCE_INDEX.md. Mark proposals and untested claims. Preserve raw responses, failures, repairs and unknowns. Never invent outcomes, citations, significance or novelty.
8. Keep communication-format and governance comparisons separate. Use equivalent requirements, tools, permissions and receiver checks when comparing workflows.
9. Use a scoped branch for changes. Inspect differences before consolidation; do not delete other assistants' work or merge doctrine conflicts automatically.
10. End substantive work with a concise handoff update: branch/commit, changed paths, checks actually performed, decisions, blockers and next action. Do not overwrite concurrent updates; reread current state first. Temporary session packages should reference durable authority rather than duplicate it.
