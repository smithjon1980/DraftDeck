# OpenMontage compatibility smoke — candidate

Authorized October 20, 2026. Upstream calesthio/OpenMontage is pinned to c8066452325cb57c8fc1ba8c2a71b6e8842e6b65. Upstream source and its AGPL-3.0 license are fetched separately; this experiment does not vendor that code into DraftDeck.

The CI job discovers the upstream provider menu, executes existing checkpoint prerequisite/resume tests, and renders the actual upstream Explainer React composition using supplied synthetic props. FFmpeg adds locally synthesized test audio and checks dimensions, duration and audio-stream presence. This is a technical subsystem test, not a completed OpenMontage agent-directed production pipeline.

The fixture lasts 45 seconds at 1920x1080 with three synthetic text scenes. No confidential manuscript, logo, paid generation API or provider secret is supplied. Narration is an explicitly synthetic espeak-ng diagnostic followed by silence; it tests stream assembly, not narration timing, voice quality or full-length speech. Captions and localization are not tested. No music is included in the diagnostic.

Upstream templated visuals may conflict with BOSS rules (gradients/orbs/typography); using brand color inputs does not establish compliance. No approved BOSS visual or audio is replaced. Remotion is the selected compatibility target because of DraftDeck's React direction; HyperFrames is not installed by this job and is not compared. No renderer selection for production follows.

Artifacts: full MP4, three sampled frames, ffprobe output, registry menu, checkpoint test XML, upstream revision/license and mechanical result. Rendering success must be followed by visual and listening inspection; retain FAIL/PENDING states. An MP4 is not an editable PDF or slide companion.

Next gate: inspect actual artifacts, then test one human-selected approved segment through the real stage/artifact/approval workflow, including scene-to-script trace, captions, provenance and a human decision. No automatic publication or research milestone change.
