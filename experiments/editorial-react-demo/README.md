# BOSS Editorial React — public synthetic compile proof

This project is the PUBLIC, NON-SENSITIVE React/Tailwind counterpart to the private four-slide source package. It is intentionally a synthetic 1–4-column fixture; it contains NO unpublished V4 narration, logo binary, original illustrations, or private hashes.

It exercises the same architectural requirements: real Vite/React JSX components, React-managed 1–4 column selection, CSS 1920×1080 slide scaling, native paragraph nodes, and a Tailwind Vite plugin build.

Run `npm install && npm run build`. This only tests that the React/Tailwind build works; private source hashes and visual fidelity are checked independently in the protected evidence package. Do not mistake a successful build for human art or release approval.
