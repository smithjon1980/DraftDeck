# BOSS Cross-Media Review

Read references/project-contract.md. Resolve actual source revisions and available artifacts through authorized reads. Record whether each item is a source, script, draft, generated candidate or reviewed release. Do not substitute a planned media map for an inspected podcast/PDF.

Trace each relevant objective, canonical statement, source fact, example relationship, operational condition and boundary to its representation in each available medium. Record missing or conflicting representations and their source references. Add timestamps and slide numbers only after inspecting the actual artifact.

Preserve complementary jobs: podcast carries story and reasoning; slides show architecture; workbook elicits performance; manual supplies reference; instructor materials govern facilitation and scoring. Do not force identical wording across media except verbatim canonical statements. Keep independent assessment answers out of learner-facing generation sources.

Enforce the candidate role map: agent = service-counter/admission/routing responsibility; model = processing capability; data/task = payload. Use shipper–clerk scenes to illustrate relationships and explicitly bridge to information work. Keep learners out of fictional shipping employment. State where packaging, payment, physical address and receipt comparisons stop.

Preserve REQUEST ≠ PACKAGE; CAPABILITY ≠ PERMISSION; GENERATED ≠ ESTABLISHED; EVAL PASS ≠ RELEASE. Preserve PRIME as PACKAGE → ROUTE → INSPECT → MOVE → ESTABLISH DELIVERY. Distinguish admission inspection from PRIME inspection. Apply permission decisions to the affected action and actual conditions; do not impose universal HOLD or manual human approval.

Return a compact correspondence table, material discrepancies, verified properties, unresolved evidence and the next bounded correction. Treat legacy role-map reconciliation as a release dependency. Modify artifacts only when authorized; keep changes traceable to the source and update compiled copies together.
