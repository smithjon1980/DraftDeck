## 2. Generation Rules
- **Do not invent doctrine.** Canonical statements exist in the sources. If a rule you want to use is not in the sources, mark it as a proposal, not a rule.
- **Every artifact teaches the same seven-module progression, but each medium performs a different instructional job.** No medium may exist merely to restate another medium.
- **The podcast explains. The deck shows. The workbook makes the learner perform. The infographic compresses. The quiz checks.**
- **If a fact is not in the sources, say so.** Prefer "the sources do not establish X" over a plausible-sounding invention.
- **A learning goal must be expressed as an observable capability whenever practical.** Generated objectives, quiz items, and exercises must follow this rule.
## 3. Terminology Rules (Mandatory)
- **BOSS — Bioscillate Operating System by Seven** is the governing system. Bioscillate is spelled B-I-O-S-C-I-L-L-A-T-E.
- **PRIME** is uppercase whenever it refers to the named protocol: Package → Route → Inspect → Move → Establish Delivery.
- **PARCELS** is the seven-layer structural architecture, not the system and not the protocol.
- **DraftDeck** is a product (the visual-production engine), never a synonym for BOSS.
- **Prohibited vocabulary:** no aviation-domain terms, no aviation-control imagery, no travel-through-meaning-space metaphors, and no predecessor product names tied to that theme. The full banned-term list is enforced by the repository ontology guard; every term on that list is prohibited in generated artifacts.

## 5. Uncertainty Rule
> **When correctness cannot be established, expose uncertainty as state rather than fabricate completeness.**
In generated artifacts: unresolved items must be visibly marked as unresolved (HELD, UNKNOWN, NOT ESTABLISHED), never silently presented as complete.

## Correspondence boundary
Logistics is a structural comparison, not a literal AI architecture. Agent and model may coexist in one application. Processing can alter content or introduce errors. Payment is not permission; a physical address is not full acceptance; a receipt is not factual verification. Clarify material unresolved conditions for the affected action only. Preserve REQUEST ≠ PACKAGE; CAPABILITY ≠ PERMISSION; GENERATED ≠ ESTABLISHED; EVAL PASS ≠ RELEASE. PRIME remains PACKAGE → ROUTE → INSPECT → MOVE → ESTABLISH DELIVERY. Admission inspection and PRIME inspection have different jobs.
