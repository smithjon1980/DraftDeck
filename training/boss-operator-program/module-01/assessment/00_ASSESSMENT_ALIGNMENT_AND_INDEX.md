# Module 01 Assessment Alignment and Index

**Version:** v1.0 candidate assessment package.
**Status:** Proposed pilot instruments; no learner outcomes or validated cut scores are claimed.

## Purpose
Make Module 01 performance observable, scoreable and reviewable. This package implements one practical assessment sequence within the existing workbook/assessment architecture. It adds no formal module or extra podcast/deck requirement.

Terminal objective: convert an operational request into a bounded work package with an established destination, scope, required inputs and acceptance conditions.

## Objective-to-evidence map
EO1 — Distinguish mission from package. Evidence: separates improving delay management from the one-page update. Rubric C1.
EO2 — Identify package boundaries. Evidence: declares included work, protected facts and excluded execution. Rubric C2.
EO3 — Identify required inputs. Evidence: selects current authoritative source and records version/provenance. Rubric C3.
EO4 — Establish destination. Evidence: asks a targeted destination question and binds the clarified recipient/location. Rubric C4.
EO5 — Establish acceptance conditions. Evidence: defines content, fidelity, review and delivery evidence before generation. Rubric C5.
EO6 — Recognize over-broad packages. Evidence: identifies the bundled “fix delays” request as a separate mission/workstream. Rubric C6.
EO7 — Reduce package scope without reducing destination scope. Evidence: excludes unnecessary contacts and stale material while preserving the recipient's needed factual coverage. Rubric C7.
Reframing overlay — Admission and permission. Evidence: classification, eligible handling and justified HOLD/ACCEPT/REFUSE. Rubric G1.
Reframing overlay — Candidate and authority. Evidence: generation, checked properties, disposition and release context remain separate. Rubric G2.

## Teaching sequence
Instructor worked example → supported practice → targeted feedback → revision → unfamiliar independent performance.
Use the main exercise as supported practice if its key or rubric anchors have been taught. It cannot then also count as unseen final evidence for that learner.
Use alternate forms for independent demonstration. Protect instructor keys and clarification replies until the relevant stage.

## Status meaning
Criterion scores describe this performance sample.
MEETS THIS TASK is not operator qualification.
A legitimate operational HOLD can be evidence of sound judgment; it is not automatically a learner failure.
Module 01 readiness also requires the other planned workbook/quiz evidence. Full operator qualification remains the seven-module/final-simulation process.

## Editorial alignment
Learner teaching passages follow BOSS Guided Reasoning Format (GRF), Candidate v1, from training/editorial/boss-guided-reasoning-format.md at commit 9d144b13f7da37570ba46dfe200f29e4a8722709 (PR 24). The format uses short reasoning steps, plain-before-technical definitions, reader-facing questions, worked cases, operator moves and explicit boundaries. It governs editorial form, not doctrine, scoring or qualification. Teaching scaffolds are omitted from independent task packets so the pilot does not mistake prompted answers for independent performance. No claim is made that the candidate editorial standard has been promoted to Controlled.
