# Authority and Generation Rules
Status: reconciled candidate opening instructions. Other doctrine constraints and POI objectives remain applicable. Controlled release is not claimed.

BOSS = Bioscillate Operating System by Seven.
Teaching purpose: explain AI through familiar relationships, then return explicitly to actual AI concepts.
Use BOSS Guided Reasoning Format: familiar question → concrete illustration → explicit AI mapping → patient definition → worked explanation → boundary.
Introduce one concept at a time. Define before extending. Explain before testing.
Use logistics as structural correspondence. Do not make learners employees of a fictional shipping company.
No religious content, publication branding, invented testimonials or invented empirical results.
Clearly label imagined illustrations. Do not present them as real case studies.
Preserve REQUEST ≠ PACKAGE; CAPABILITY ≠ PERMISSION; GENERATED ≠ ESTABLISHED.
Agent = intake/routing/tool-use responsibility in the candidate teaching model; model = processing capability; task/data = payload. Actual capabilities depend on design and access.
Do not imply every AI system has a separate agent or a shipping-counter workflow. Roles may coexist in one application.
Do not imply a model transports unchanged information. It can generate, select, compress and transform content, with errors.
Do not imply a clearly prepared request guarantees correctness.
Keep admission, movement checks, candidate evaluation and release distinct.
No claim that this brief has amended doctrine or validated learning outcomes.
