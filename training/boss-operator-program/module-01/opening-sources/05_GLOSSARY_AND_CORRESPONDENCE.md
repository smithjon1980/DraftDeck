# Shared Glossary and Correspondence
| Concept | Plain definition | Shipping comparison and limit |
|---|---|---|
| Request | Intended work expressed to a system | Sender's instruction; not necessarily sufficient task definition |
| Input | Information available for processing | Material presented; digital processing can alter or generate content |
| Prompt | Instruction/content presented to a model | No exact parcel equivalent; do not force the mapping |
| Package | BOSS bounded task, necessary information and conditions | Prepared shipment; a BOSS operational construct |
| Agent | System coordinating actions/tool use toward a task | Counter responsibility; actual autonomy and permissions vary |
| Model | Learned computational system supplying processing capability | Processing resource; not the parcel or a literal carrier |
| Candidate result | Generated work awaiting relevant checks for use | No exact unchanged-parcel equivalent |
| Admission | Whether specified information may enter processing under applicable conditions | Acceptance check; capability alone does not establish permission |
| Adjudication | Evidence-based disposition of a candidate for intended use | Receipt alone does not establish accuracy or release authority |

Teach distinctions through the document-explanation illustration. Recognition of logistics vocabulary alone is not evidence of understanding AI.
