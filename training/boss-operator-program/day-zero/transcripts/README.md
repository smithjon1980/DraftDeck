# Day Zero Transcript Archive

**Status:** Controlled archive rule  
**Scope:** Day Zero NotebookLM and other generated audio transcripts

Every completed transcript must be archived in **both GitHub and Google Drive**.

## Required dual archive

For each audio overview or subsequent Day Zero recording:

1. Preserve the original audio in the designated Google Drive WIP audio-output lane.
2. Preserve the verbatim Markdown transcript in the same Google Drive WIP lane.
3. Commit the same transcript Markdown to this GitHub transcript archive.
4. Keep filenames revision-specific; never overwrite a prior transcript revision.
5. Treat generated transcripts as WIP until reviewed and adjudicated.
6. Do not move a transcript to FINAL merely because ASR completed successfully.
