# Day Zero Orientation Source

**Revision:** v2.0 — Reframed Day Zero
**Status:** Candidate training material; not a controlled release.

## The work you already do
Every day you move information between people, systems, models, files and applications. You send a document, ask for a summary, transform a draft, or hand a result to another person. Useful work requires more than a tool returning something. We need to know what was committed, where information could go, what was produced, and what evidence permits its use.

BOSS — Bioscillate Operating System by Seven gives this work a governed structure. A parcel counter is a useful comparison because it exposes declaration, handling, acceptance and delivery conditions. The correspondence is structural. You remain a person governing information work.

## The complete interaction
A need becomes a request. An agent helps align the request and construct an accountable package. Admission checks whether required information and authority are sufficient. Handling classification constrains eligible models, tools and runtimes before selection. An admitted package moves along an authorized route. Execution produces a candidate. Evidence supports adjudication. Applicable release authority establishes whether the result may be used in the intended context.

Admission governs input. Adjudication governs output. Capability governs neither by itself.

## Request and package
“Make this presentation better” expresses a need. It may omit the audience, source version, output format, protected content, delivery location or acceptance conditions.

REQUEST ≠ PACKAGE.

A governed package identifies purpose, authoritative inputs, scope, output destination, constraints, handling requirements, permitted destinations and handlers, and evidence of acceptable delivery. The package is the unit of accountability. A block is the unit of operational commitment and can contain several accountable packages.

A good agent uses what is already known and asks only for required missing decisions. It does not invent an audience or permission. Routine choices may be made within a granted envelope. A missing decision outside that envelope produces HOLD and clarification or escalation.

## The agent as service counter
The counter represents an admission boundary. In information work, an agent performs intake, package construction, admission control, classification, routing and delivery establishment. It may coordinate several capabilities. The analogy does not guarantee that every AI product implements these controls.

The sender supplies purpose and necessary truth. The agent structures and checks the work. Neither invents missing requirements. The model is processing capability; the data and task are the payload. Selecting the most powerful model does not establish what the work is or whether that model may receive it.

## Admission, classification and permission
Admission Inspection asks: May this package enter controlled movement?

ACCEPT means the declared package meets the applicable entry conditions.
HOLD means a required condition is unresolved; stop the affected movement and resolve it.
REFUSE means the proposed package or movement is not eligible under the applicable requirements.

At orientation depth, handling states are STANDARD / SENSITIVE / RESTRICTED / QUARANTINED / PROHIBITED. They describe movement controls, not truth or moral worth.

Cargo classification precedes handler selection.
CAPABILITY ≠ PERMISSION.
CAN PROCESS ≠ MAY RECEIVE.
Unknown handling requirements produce HOLD, not guessed routing.

An external service may summarize a file well while being ineligible to receive its contents. A sanitized extract can sometimes satisfy the task with less information movement. Eligibility still must be established. The minimum necessary cargo should travel.

## PRIME after admission
PACKAGE → ROUTE → INSPECT → MOVE → ESTABLISH DELIVERY

PACKAGE: identify the bounded work and retain its declaration.
ROUTE: select an eligible path from the requirements.
INSPECT: check conditions for this particular action or transfer.
MOVE: execute the bounded action.
ESTABLISH DELIVERY: establish that the intended result reached the intended destination in an acceptable state with evidence and proper release authority.

Admission Inspection is an entry decision. PRIME INSPECT checks a particular movement. Do not collapse them.

## Generated output remains a candidate
GENERATED ≠ ESTABLISHED.
OUTPUT ≠ VERIFIED RESULT.
PRODUCED ≠ AUTHORIZED.

A fluent summary can omit a qualification. A rendered deck can lose editable text. A successful upload can carry the wrong revision. Execution evidence proves that an action occurred; it does not by itself establish that the intended result is acceptable.

Adjudication compares the candidate with acceptance conditions and relevant evidence. Depending on the work, evidence can include deterministic checks, source comparison, tests, independent evaluation, policy checks, human review or a combination. Possible dispositions are ACCEPT / REVISE / REJECT / ESCALATE. An accepted candidate still requires applicable release authority.

The burden of adjudication scales with consequence, not confidence, fluency or model capability. Manual human approval is not universally required. Higher-consequence work may require independent review or explicit human release. For lower-consequence work, sufficient deterministic checks and an already authorized release rule may suffice.

BUILD_CAPABILITY ≠ REVIEW_CAPABILITY ≠ RELEASE_AUTHORITY.
EVAL PASS ≠ RELEASE.

## Worked example: an editable Day Zero deck
Request: Rebuild orientation slides for the reframed course.
Package: approved source revision, learner audience, slide arc, white 16:9 canvas, CAD visual rules, editable text, destination and acceptance conditions.
Admission: confirm access, permitted handling, scope and declared production route.
Execution: DraftDeck creates HTML/CSS/SVG and a browser-rendered candidate.
Adjudication: compare content to source; inspect visual fidelity, live text, layer order and import editability. A browser render proves only the properties actually checked.
Release: establish a reviewed version for its stated use through the applicable authority. A polished Canva page is still a candidate until its requirements are established.

No generic presentation generator or PowerPoint intermediary may replace the declared route.

## Seven formal modules
01 Package Operations: define and admit accountable work.
02 Route Operations: choose eligible paths.
03 Facility Operations: govern many packages within an environment.
04 Transfer Operations: preserve identity, authority, context and evidence at handoff.
05 Transport Coordination: match requirements to handling capability and placement.
06 High-Control Operations: strengthen controls as consequence rises.
07 Network Orchestration: coordinate dependencies while preserving package accountability.

Day Zero prepares you to start Module 01. Training, qualification, certification, credentialing and operational authorization remain distinct.

## Readiness
Explain what may enter, what may handle it, what was produced, what evidence supports it, and what authority establishes its use. Carry these questions into Module 01, where package construction becomes practical work.
