# Day Zero — Network Orientation

**Status:** Candidate Training Package  
**Owner:** BOSS — Bioscillate Operating System by Seven  
**Program position:** PRE-ENTRY → DAY ZERO → MODULES 01–07  
**Authority:** Subordinate to BOSS doctrine and the BOSS Operator Program Plan of Instruction.

Day Zero prepares an accepted learner to enter formal training. It is orientation and calibration, not one of the seven training modules.

> **Day Zero establishes the learner's initial routing state before curriculum movement begins.**

## Day Zero orientation blocks

1. **Entry State** — why the learner is here and what acceptance does and does not mean.
2. **System Identity** — BOSS, Bioscillate Logistics Framework, PARCELS, PRIME.
3. **Information Logistics** — cargo, packages, routes, handlers, verification, release.
4. **Authority & Handling Boundaries** — CAPABILITY ≠ PERMISSION; HOLD is valid; restricted cargo basics.
5. **PRIME Orientation** — Package → Route → Inspect → Move → Establish Delivery.
6. **Training Journey** — Modules 01–07; TRAINED ≠ QUALIFIED ≠ CERTIFIED ≠ CREDENTIALED ≠ AUTHORIZED.
7. **Learning Envelope & Clearance** — baseline diagnostic, learner-state record, orientation clearance.
