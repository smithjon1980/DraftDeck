# Day Zero Orientation Clearance

**Status:** Candidate Clearance Instrument  
**Purpose:** Verify minimum orientation understanding before Module 01.

> **Orientation clearance ≠ operator qualification.**

## Clearance checks

The learner must demonstrate all of the following:

1. Identifies BOSS as the governing system.
2. Distinguishes system / framework / architecture / protocol / product at orientation depth.
3. States PRIME in correct sequence.
4. Explains CAPABILITY ≠ PERMISSION.
5. Recognizes HOLD as valid when required handling information is unresolved.
6. Distinguishes TRAINED / QUALIFIED / CERTIFIED / CREDENTIALED / AUTHORIZED.
7. Completes the Learning Envelope.
8. Completes the initial diagnostic.
9. Accepts the initial route or records a routing concern for adjudication.

## Clearance states

### CLEARED FOR MODULE 01
All minimum orientation requirements established.

### CLEARED WITH REMEDIATION
Orientation requirements established, but bounded gaps should be addressed alongside or before early Module 01 work.

### HOLD — ORIENTATION REQUIREMENT UNRESOLVED
A required condition is missing or unresolved. Do not guess a clearance state.

## Evidence record

For each check record:
- PASS;
- NEEDS REMEDIATION;
- UNRESOLVED.

The instructor must cite the observed evidence used for the decision.
