# Day Zero Orientation Clearance

**Revision:** v2.0 — Reframed Day Zero
**Status:** Candidate training material; not a controlled release.

## Purpose
Orientation clearance ≠ operator qualification.

## Mandatory demonstrations
1. Identify BOSS; distinguish system, framework, architecture, protocol and product.
2. Explain REQUEST ≠ PACKAGE and the agent service-counter responsibility.
3. Explain classification before handler selection, CAPABILITY ≠ PERMISSION and CAN PROCESS ≠ MAY RECEIVE.
4. Identify HOLD for unresolved required conditions.
5. State PRIME and distinguish Admission Inspection from PRIME INSPECT.
6. Explain candidate output and output adjudication.
7. Select evidence appropriate to consequence without asserting universal manual approval.
8. Distinguish building, reviewing and release authority; explain EVAL PASS ≠ RELEASE.
9. Distinguish TRAINED / QUALIFIED / CERTIFIED / CREDENTIALED / AUTHORIZED.
10. Complete Learning Envelope and diagnostic.
11. Confirm the instructional plan or record a concern for adjudication.
