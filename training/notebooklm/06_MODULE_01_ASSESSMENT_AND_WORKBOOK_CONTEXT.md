# 06 — Module 01 Assessment & Workbook Context

**Document role:** Brief for Quiz 01 and the Module 01 workbook exercises. The workbook owns performance; the quiz produces evidence.

---

## 1. Governing Rules

> **CONTENT DELIVERED ≠ LEARNING ESTABLISHED.**

> **QUIZ PASS ≠ OPERATOR QUALIFICATION.**

> **A learning goal should be expressed as an observable capability whenever practical.**

> **Self-reported proficiency informs routing; demonstrated performance provides the primary evidence for instructional state.**

The workbook does not ask "What does this term mean?" It asks **"What would you do with this package, and why?"**

## 2. Quiz 01 — Package Operations

**Structure:** three evidence types, applied questions carry the most weight.

### Recall (can the learner identify the concept?)
Sample items:
- What are the six required declarations of a bounded package? (identity, contents, scope boundary, destination, required inputs, acceptance condition)
- Which is the unit of accountability: the block or the package?
- State the rule: "Undefined cargo cannot be ______."

### Classification (can the learner recognize the correct state/rule?)
Sample items:
- Given four work requests, classify each: bounded package vs. mission-as-package vs. unbounded prompt vs. scope-stuffed package.
- A request reads "summarize this — I'll know what I need when I see it." Which failure mode?
- True/false: attaching extra source material "just in case" satisfies minimum necessary cargo.

### Application (can the learner select the correct operational response?)
Sample items:
- Given "clean up the customer data," select the best bounded-package rewrite from four options (correct answer names destination, acceptance, inputs, scope).
- A package's acceptance condition cannot be stated. Choose the correct response: decompose or hold — not "start anyway."
- Given a 90-page bundle attached to a two-paragraph deliverable, choose the minimum-necessary-cargo action.

## 3. Workbook — Module 01 Exercises

**Exercise 1 — Bound and define.** Convert three vague requests into bounded packages with destination and acceptance conditions. (Requests supplied by instructor; one must be from the learner's actual work.)

**Exercise 2 — Decompose.** Take one over-broad package ("produce the annual compliance report") and decompose it into three bounded packages. Rule under test: reduce package scope without reducing destination scope.

**Exercise 3 — Minimum necessary cargo.** Given a package with 12 attachments and a two-sentence deliverable, decide what travels and what does not; justify each removal.

**Exercise 4 — Failure-mode inspection.** Given five sample requests, identify the failure mode in each and write the one-line correction.

## 4. Success Evidence

Module 01 is established when the learner, unprompted and on novel material:

- converts a vague request into a bounded package with destination, scope, inputs, and acceptance condition;
- correctly identifies over-broad packages and decomposes them;
- applies minimum necessary cargo with justification.

> Completion of the exercises is movement. Demonstrated capability on novel material is delivery.

## 5. Instructor Notes (summary)

- Score applied items highest; a learner who can define a package but cannot bound one is NOT ESTABLISHED.
- Watch for retrofitted acceptance ("the output looks fine, so the condition was met") — this is the most common hidden failure.
- Feed observed gaps back as learner-state updates; do not route the learner to Module 02 on quiz score alone.
