# DraftDeck archive notes

The current repository intentionally retains only artifacts that remain valid under the Logistics Framework.

The original 15-slide production experiment established several durable facts that survive the terminology migration:

- static HTML/CSS can preserve separate live text and artwork layers;
- the 16:9 build can be regenerated deterministically from authored source;
- the Canva import route can preserve editable rich-text records and separate image records;
- successful import and high layer counts do not prove visual fidelity;
- generated output must never become the authoring source.

Deprecated predecessor reference bundles, generated previews, and manifests that encoded the retired travel/aviation theme were removed from the current tree. Their provenance remains available in Git history rather than in active project content.

The current flagship source lives at `examples/logistics-framework/`, and current doctrine lives in `doctrine/logistics-framework.md`.
